# Phantom Habits

App de hábitos estilo Persona 5. Cada hábito suma XP a un stat (Conocimiento, Físico, Carisma) y los stats suben de nivel.

## Probarla
Abre `index.html` en el navegador. No necesita instalar nada.

## Subirla a GitHub
1. Crea un repositorio vacío en github.com (sin README).
2. En esta carpeta: `git remote add origin URL_DEL_REPO` y luego `git push -u origin main`.

## Convertirla en APK
1. Activa GitHub Pages (Settings → Pages) para tener una URL pública.
2. Pega esa URL en https://www.pwabuilder.com y descarga el paquete de Android.
